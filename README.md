# Student Results Lookup

This repository contains a simple static website for viewing student academic results. A parent or student enters an assigned access number, and the website displays the matching academic result notice in the browser.

## Purpose

This project is an educational results lookup page. It is designed for displaying non-sensitive academic information such as course performance, learning progress, and lesson-level feedback.

## Access Numbers

Each student is assigned a random access number by the school. These numbers are only lookup keys used by the website. They are not government identification numbers, passwords, payment information, authentication tokens, or security credentials.

## Data and Privacy

The intended deployment contains no sensitive security information. Do not upload government IDs, contact details, home addresses, health records, financial information, passwords, authentication data, or other sensitive personal information.

The `data.json` file is generated by the school follow-up application. The application can generate notices either with student names or without student names. Use the **without names** option when a minimal public display is preferred.

## Deployment

Place the following files in the same public folder of a static host such as GitHub Pages:

```text
index.html
data.json
```

The `data.json` file is exported from the school follow-up application using **Export data.json — All Classes**. After grades are updated, export a new `data.json` file and replace the old one on the website.

> Open this project through a web server or static hosting provider. Opening `index.html` directly from a device file manager may prevent the browser from loading `data.json`.

## Technical Notes

This is a client-side static website. It loads `data.json`, matches the entered access number, and displays the corresponding HTML result notice directly in the page. No backend, payment feature, account system, or security service is included.
