# صفحة البحث عن النتائج

## الملفات المطلوبة للنشر

ضع ملفي `index.html` و`data.json` في **المجلد نفسه** داخل مستودع GitHub Pages. ملف `data.json` تصدره من برنامج كشف المتابعة عبر زر **«تصدير data.json — جميع الفصول»**.

> لا تفتح `index.html` مباشرة من تطبيق «الملفات»؛ لأن المتصفح يمنعها غالباً من قراءة `data.json` محلياً. افتحها من رابط GitHub Pages أو أي استضافة ويب ثابتة.

## طريقة التحديث

بعد إدخال درجات أو تغييرات جديدة، صدّر `data.json` من البرنامج مجدداً ثم استبدل الملف القديم في المستودع. لا تحتاج إلى تغيير كود صفحة البحث في كل تحديث.

## نمط الاسم

يختار برنامج كشف المتابعة عند التصدير بين إشعارات **بالأسماء** أو **بدون أسماء**. صفحة البحث تعرض HTML الذي موجود داخل `data.json` كما هو.

## ملاحظة

تتحقق الصفحة من الرقم وتعرض الإشعار المطابق، لكنها لا تضيف طبقة حماية خادمية؛ لأن ملف `data.json` يكون منشوراً مع الموقع.
